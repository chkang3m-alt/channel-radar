Channel Radar

한국 리테일 채널 뉴스 데일리 다이제스트

Channel Radar 는 한국 리테일 채널(대형마트·편의점·이커머스·균일가점 등) 관련 공개 뉴스 기사를 매일 아침 모아 요약하고, 운영자 본인에게 이메일 한 통으로 보내는 개인용 도구입니다. 공개 서비스가 아니며 가입이나 구독 기능이 없습니다.

무엇을 하나

  • 공개된 뉴스 검색 결과에서 전날 기사 목록을 모은다
  • 중복 사건을 묶고, 관련도 기준으로 10건 이내를 고른다
  • 각 기사의 요약을 만들어 HTML 이메일로 구성한다
  • 운영자 본인의 Gmail 계정에서 운영자 본인에게 발송한다

누가 쓰나

운영자 한 사람입니다. 다른 사용자를 받지 않습니다.

Gmail 권한

발송을 위해 Gmail API 의 gmail.send 범위 하나만 사용합니다. 메일을 읽거나, 지우거나, 메일함을 조회하는 권한은 요청하지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.
