Channel Radar · 최종 수정 2026-10-12

Channel Radar 는 운영자 한 사람이 자신에게 뉴스 요약 메일을 보내기 위해 쓰는 개인용 도구입니다. 다른 사용자를 받지 않으며, 방문자로부터 어떤 정보도 수집하지 않습니다.

Google 사용자 데이터

이 앱은 Gmail API 의 gmail.send 범위 하나만 요청합니다. 이 범위는 메일을 보내는 것만 허용합니다. 앱은 다음을 하지 않습니다.

  • 메일을 읽거나 검색하지 않는다 (권한 자체가 없다)
  • 연락처·캘린더·드라이브 등 다른 Google 데이터에 접근하지 않는다
  • Google 사용자 데이터를 저장·보관하지 않는다
  • Google 사용자 데이터를 제3자에게 전송·판매·공유하지 않는다
  • Google 사용자 데이터를 광고나 모델 학습에 쓰지 않는다

Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건(Limited Use)을 따릅니다.

인증 정보 보관

OAuth 리프레시 토큰은 운영자의 개인 컴퓨터와, 발송 자동화를 돌리는 저장소의 암호화된 비밀 저장소(GitHub Actions Secrets)에만 보관됩니다. 공개되지 않으며 소스 코드에 포함되지 않습니다. 권한은 Google 계정 설정에서 언제든 철회할 수 있습니다 (myaccount.google.com/permissions).

처리하는 내용

앱이 다루는 것은 공개된 뉴스 기사의 제목·링크·요약과 대표 이미지입니다. 이 내용은 운영자 본인에게 보내는 메일과, 이 사이트의 다이제스트 페이지에 실립니다. 개인정보는 처리하지 않습니다.

방문자

이 사이트는 GitHub Pages 로 제공되는 정적 페이지입니다. 쿠키를 쓰지 않고, 분석 도구를 넣지 않았으며, 방문자 정보를 수집하지 않습니다.
